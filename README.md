# 项目人员调度台 2.7.0

面向 AI 漫剧 / 影视制作团队的 Windows 10/11 离线项目资料、人员资料、产能规划与资源调度桌面软件。业务数据保存在当前电脑，不依赖云端服务。

## 2.7.0 核心能力

### 业务工作台

- **项目资料库**：项目类型、制作要求、场数/集数、客户、结算、启动日期、DDL、剧本/美术资料、资产/视频/总进度、内审、风险、资料链接等。
- **人员资料库**：部门、多个职位、技能标签、分方向制作能力、标准产能、当前项目、历史项目、实际产出、头像和在岗状态。
- **双向分工记录**：项目团队和人员参与项目统一来自 Assignment，避免两边数据不一致。
- **团队规则**：导演/负责人、编导、PM、美术监制、视频、资产等岗位支持多人安排；阶段完成后按规则释放人员产能。
- **Excel / CSV 导入**：提供项目与人员 `.xlsx` 模板，支持重名更新和缺失人员建档。

### Planning Center 规划中心

- **30 / 60 / 90 天产能预测**：按人员和团队预测未来占用、可用产能、满载与超载情况。
- **公司工作日历**：周工作日、公司休息日、特殊补班日都会真实影响预测、推荐和排期。
- **团队产能热力图**：按日查看利用率、可用产能和冲突人数。
- **Resource Gantt / Project Gantt**：统一查看人员占用、项目周期、团队分工、里程碑和 DDL。
- **解释型人员推荐**：综合职位、技能、未来产能、冲突和最早可用日期给出候选排名。

### 自动排期与优化

- **Dependency Gate**：前置项目条件未满足时，后续项目保持 blocked，不会提前占用人员。
- **关键路径优先队列**：多个 ready 需求争抢稀缺人员时，按关键路径、DDL 延误、P0-P3、浮动时间和人员缺口排序并逐需求预留模拟产能。
- **解释型优先分**：Priority Queue 可展开查看每项加减分，明确说明“为什么这个项目先拿人”。
- **多策略优化**：比较均衡、少人集中、分散低负荷、细粒度灵活等资源组合；支持综合最优、按期优先、低风险优先、少人集中优先。
- **DDL 安全边界**：候选人员如果只能在项目结束日之后空闲，不会生成无效排期建议。
- **原子应用**：方案先在模拟数据库中验证，确认后整批一次写入；任一命令失败则整批不落库。

### 项目网络与关键路径

- 支持 FS / SS / FF / SF 四类项目依赖及工作日 Lag / Lead。
- 支持自定义业务里程碑，并结合资产完成、视频完成和 DDL 等内置里程碑。
- CPM 计算最早/最晚开始和完成日期、总浮动时间、主关键链和 DDL 风险。
- 循环依赖在写入前直接拒绝，并根据前置项目实际状态计算 readiness / blockers。

### What-if 情景沙盘

可以在不修改真实数据库的情况下比较多个假设方案：补齐用人需求、转移现有分工、模拟人员状态/产能变化、模拟项目启动日期/DDL/状态变化，并比较需求缺口、冲突、利用率和未来可用产能。选中情景后再原子应用。

### Undo / Redo 与操作审计

- manager / admin 的真实修改按事务记录，可整单撤销和重做。
- 自动排期、优化方案、情景沙盘等多命令操作作为一个事务处理。
- 持久审计记录操作者、时间、事务标签、命令类型和执行 / 撤销 / 重做动作。
- Undo / Redo 快照仅保存在当前会话内，避免长期 JSON 数据库持续膨胀。

### 数据安全与恢复

- 离线账号与权限：高级管理员、调度管理员、只读账号分级控制。
- 首次启动和人员账号创建使用随机临时密码，首次登录必须修改；正式密码使用加盐密码派生算法保存。
- 支持业务 JSON 手工备份 / 恢复。
- 桌面端覆盖数据库前自动保留滚动恢复点。
- Planning Center 可查看数据库大小、版本、最近写入和 SHA-256，并由管理员恢复历史版本。

## Windows 构建产物

2.7.0 构建包含：

- `项目人员调度台-Setup-2.7.0-x64.exe`：安装版，可选择安装目录并创建桌面快捷方式。
- `项目人员调度台-Portable-2.7.0-x64.exe`：便携版，无需安装。

## 本地开发

```bash
npm install
npm run templates
npm start
```

运行完整测试：

```bash
npm test
```

## 生成 Windows 安装包

```bash
npm ci
npm run templates
npm run build:win
```

GitHub Actions 的 `Build Windows Installer` 会在 PR、`main` 更新和 `v*` 标签时执行测试、模板生成、Windows Setup / Portable 构建与产物上传。

## 生产使用建议

首次正式录入前，建议先用少量测试项目验证公司的职位、技能、产能和工作日历设置；确认业务规则后再导入正式项目。正式使用期间建议定期导出业务 JSON 备份，同时保留应用自动生成的滚动恢复点。

## 版本

当前稳定目标版本：**2.7.0**。

2.7.0 将项目人员调度台从“项目 / 人员资料 + 当前产能调度”升级为包含未来产能预测、依赖网络、关键路径、解释型优先队列、多方案优化、What-if 沙盘和事务级安全回滚的离线资源规划工作台。
